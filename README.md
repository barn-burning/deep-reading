# deep-reading

중·고등학생을 위한 작품 깊이읽기(톺아보기) 실험 프로젝트.

## 문제의식

문학 학습은 자주 `작품 → 해설 → 문제 → 정답`의 흐름으로 끝난다.  
deep-reading은 작품의 의미를 대신 설명하기보다, 사용자가 스스로 생각을 확장하고 조직하도록 돕는 **사고의 비계(scaffolding)** 를 제공한다.

이 서비스는 교과서, 교사, 작품 원문을 대체하지 않는다.  
사용자가 이미 읽었거나 떠올린 작품을 바탕으로 질문을 이어가며 다음과 같은 경험을 만드는 것이 목적이다.

- 자신의 첫 반응을 언어화하기
- 인물·장면·표현에 다시 주목하기
- 해석에 텍스트 근거를 붙이기
- 다른 해석 가능성을 검토하기
- 시대·사회·문화적 맥락으로 관점을 이동하기
- 처음 생각과 달라진 지점을 스스로 확인하기
- 생각·사실·가설·남은 질문을 구분하기

## 핵심 원칙

> 첫 질문은 좋은 질문보다 대답할 수 있는 질문이어야 한다.

> 비계는 사고를 대신하지 않고, 다음 한 걸음을 가능하게 해야 한다.

> 생각을 '맞게' 만드는 것이 아니라, 더 정교하게 만든다.

AI는 정답으로 유도하는 해설자가 아니라 **좋은 발문자**다.  
학생의 현재 사고 수준보다 한 단계만 앞선 질문을 제시하고, 충분히 깊어진 경우에는 질문을 억지로 이어가지 않는다.

## MVP

초기 버전은 로그인·결제·작품 원문 DB 없이 한 세션의 품질 검증에 집중한다.

1. 작품명 입력
2. 중학생 / 고등학생 수준 선택
3. 대답하기 쉬운 첫 질문
4. 사용자 답변에 따른 적응형 후속 발문
5. 대화와 동시에 '사고 흐름' 기록
6. 세션 종료 시 탐구 노트 생성

예상 화면 구조:

- 왼쪽: 작품 톺아보기 대화
- 오른쪽: 사고 흐름
  - 핵심 요지
  - 사고 유형
  - 새롭게 생긴 질문
  - 생각의 변화

## 비목표

초기 단계에서는 다음을 하지 않는다.

- 작품 전문 제공
- 교과과정 전체 대체
- 문제은행 / 시험 대비 서비스
- 정답형 문학 해설 생성
- LMS, 학급 관리
- 로그인 / 구독 / 결제
