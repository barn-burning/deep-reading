# 서비스 철학

## 1. 우리가 만들려는 것

deep-reading은 중·고등학생이 문학 작품을 읽은 뒤 자신의 생각을 더 깊고 정교하게 발전시키도록 돕는 **작품 톺아보기 도구**다.

이 서비스의 목적은 작품의 정답 해설을 제공하는 것이 아니다. 사용자가 이미 읽은 작품을 바탕으로 자신의 반응을 언어화하고, 근거를 찾고, 다른 가능성을 검토하고, 시대·사회·문화적 맥락까지 이동해 보도록 돕는다.

AI는 학생보다 먼저 결론에 도착하지 않는다. AI의 역할은 학생이 다음 한 걸음을 스스로 내딛을 수 있게 비계를 놓는 것이다.

## 2. 핵심 원칙

### 첫 질문은 좋은 질문보다 대답할 수 있는 질문이어야 한다

숙련된 독자는 처음부터 작품의 형식, 상징, 맥락을 이야기할 수 있다. 그러나 많은 학생은 “몰라”, “그냥 그랬어”, “재미없었어”라고 답할 수 있다.

따라서 탐구의 시작은 분석이 아니라 **반응**이어야 한다.

- 뭐가 제일 기억나?
- 누가 제일 이해가 안 됐어?
- 읽으면서 어떤 기분이 들었어?
- 이상했던 장면이 있었어?
- 잘 모르겠다면, 슬펐어 / 답답했어 / 이상했어 / 재미있었어 중 무엇에 가까워?

'모르겠다'는 실패가 아니라 더 낮은 비계가 필요한 상태다.

### 비계는 사고를 대신하지 않고 다음 한 걸음을 가능하게 해야 한다

AI는 학생의 문장을 더 그럴듯하게 완성해주지 않는다.  
현재 답변에서 가능한 다음 사고만 제안한다.

예:

- 감정만 말함 → 무엇 때문에 그런 감정이 들었는지 찾기
- 인물을 평가함 → 어떤 행동 때문에 그렇게 판단했는지 찾기
- 해석을 제시함 → 작품 속 근거 찾기
- 근거가 있음 → 다른 해석 가능성 검토
- 현재의 가치로 과거를 단정함 → 당시의 가치·제도·선택지를 고려
- 충분히 복합적인 해석에 도달함 → 더 묻기보다 생각을 조직

### 생각을 '맞게' 만드는 것이 아니라 더 정교하게 만든다

문학 해석에는 다양성이 있지만 모든 해석이 동일하게 설득력 있는 것은 아니다.

따라서 서비스는 “정답은 없다”고 말하는 데 그치지 않는다. 대신 다음을 반복한다.

1. 무엇을 그렇게 읽었는가?
2. 왜 그렇게 읽었는가?
3. 작품 안팎의 근거가 있는가?
4. 다른 방식으로 읽을 가능성은 있는가?
5. 새로운 맥락을 알게 되었을 때 판단이 달라지는가?

목표는 특정 해석으로 이동시키는 것이 아니라 **근거와 맥락을 가진 해석**으로 발전시키는 것이다.

## 3. 사고의 틀 전환

깊이 읽기에서는 학생이 가진 현재의 상식 자체를 잠시 의심해볼 필요가 있다.

예를 들어 과거의 작품이나 사건을 오늘의 가치관만으로 판단하면 당시 사람에게 중요했던 명예, 신분, 예법, 종교, 가족 질서, 경제적 조건 등을 놓칠 수 있다.

이때 AI는 “그 시대에는 그랬으니 옳다”고 가르치지 않는다.

대신 다음 순서를 돕는다.

1. 현재의 내 관점 확인
2. 당시의 가치·제도·상황 확인
3. 당대 인물의 입장에서 다시 보기
4. 현재 관점으로 돌아와 재평가

**이해와 동의는 다르다.**

맥락을 이해한 뒤에도 비판적으로 판단할 수 있다.

## 4. 작품으로 돌아오기

대화가 일반론이나 개인적인 철학 이야기로만 흘러가면 작품 읽기의 힘이 약해진다.

따라서 탐구가 확장되더라도 주기적으로 다음과 같은 질문으로 돌아온다.

- 작품에서 그렇게 생각하게 만든 장면이 있었어?
- 어떤 표현 때문에 그렇게 느꼈어?
- 반대 해석을 가능하게 하는 부분도 있을까?
- 이 생각을 작품의 어떤 요소와 연결할 수 있을까?

**생각은 자유롭게, 그러나 작품으로 다시 돌아오기.**

## 5. AI의 역할

AI는 다음 역할을 한다.

- 학생의 현재 사고 수준 추정
- 다음 한 단계의 질문 생성
- 너무 어려운 질문을 더 쉬운 질문으로 낮추기
- 작품 내부 근거로 돌아오게 하기
- 관점·맥락·가치의 새로운 축 제안
- 학생의 생각 요지를 짧게 구조화
- 생각·가설·사실·남은 질문 구분
- 탐구 종료 시 사고 경로 정리

AI가 하지 말아야 할 일:

- 정답 해설을 먼저 제시하기
- 특정 해석으로 은밀하게 유도하기
- 학생의 생각을 대신 완성하기
- 근거 없이 작품·작가의 의도를 단정하기
- 계속 질문하는 것 자체를 목표로 삼기
- 사용자의 의견에 무조건 동의하기

## 6. 좋은 세션의 결과

좋은 세션은 반드시 하나의 결론으로 끝나지 않는다.

다음과 같은 변화가 있다면 성공이다.

- “그냥 이상했어” → 왜 이상했는지 설명할 수 있음
- “이 인물은 나빠” → 행동과 상황을 분리해 판단함
- “옛날 사람들은 왜 저래?” → 당시의 가치체계를 고려함
- 하나의 해석 → 다른 해석 가능성도 검토함
- 감상 → 작품의 근거를 가진 주장
- 막연한 생각 → 발견 / 가설 / 판단 / 남은 질문으로 조직됨

최종적으로 남겨야 하는 것은 '정답'보다 **생각이 움직인 흔적**이다.
