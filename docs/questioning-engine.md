# 발문 엔진 v0.1

## 목적

학생의 답을 맞고 틀림으로 채점하지 않고, **현재 사고 상태를 판별해 다음 한 걸음을 제시**한다.

기본 흐름은 다음과 같다.

```
반응
→ 대상/장면
→ 이유
→ 해석
→ 근거
→ 다른 가능성
→ 맥락
→ 재평가
→ 성찰/정리
```

이 흐름은 고정된 코스가 아니다. 학생의 답변에 따라 건너뛰거나 되돌아간다.

## 사고 상태와 다음 비계

### S0. 반응 없음

예:
- 몰라
- 기억 안 나
- 잘 모르겠어

목표: 답할 수 있는 가장 낮은 진입점을 제공한다.

발문:
- “그럼 느낌부터 골라볼까? 슬펐어 / 답답했어 / 이상했어 / 재미있었어 / 잘 모르겠어”
- “기억나는 인물 한 명만 떠올려볼래?”
- “좋았던 장면이 아니어도 돼. 이상했던 부분은 있었어?”

금지:
- 추상적 해석 요구
- “왜 그렇게 생각해?”만 반복

### S1. 감정 반응

예:
- 답답했어
- 슬펐어
- 짜증났어

목표: 감정의 대상을 특정한다.

발문:
- “뭐 때문에 가장 답답했어?”
- “특정 인물 때문이야, 사건 때문이야?”
- “그 느낌이 가장 강했던 장면이 있어?”

### S2. 대상/장면 언급

예:
- 아빠가 이상했어
- 마지막 장면
- 주인공이 친구를 숨겨준 부분

목표: 판단의 이유를 언어화한다.

발문:
- “그 행동에서 뭐가 가장 이상했어?”
- “왜 그 장면이 기억에 남았을까?”
- “그때 인물이 왜 그렇게 했다고 생각해?”

### S3. 해석 제시

예:
- 무서워서 그런 것 같아
- 친구를 지키려고 한 것 같아
- 작가가 현실을 비판하려고 한 것 같아

목표: 해석을 근거와 연결한다.

발문:
- “그렇게 생각하게 만든 장면이나 표현이 있어?”
- “작품 안에서 그 생각을 뒷받침하는 단서를 하나 떠올려볼까?”
- “그 해석을 가장 잘 보여주는 행동은 뭐였어?”

### S4. 근거 있는 해석

예:
- 이 장면에서 말을 피했기 때문에 두려웠다고 봤어
- 반복되는 표현 때문에 불안이 강조된 것 같아

목표: 해석의 단일성을 흔들고 다른 가능성을 연다.

발문:
- “같은 장면을 다르게 볼 수도 있을까?”
- “반대로 해석할 만한 단서는 없었어?”
- “다른 인물의 입장에서는 이 장면이 어떻게 보였을까?”

### S5. 복합적 해석

예:
- 개인의 선택도 있지만 당시 사회적 압박도 있었던 것 같아
- 사실적인 서술과 환상성이 충돌하면서 오히려 비극성이 강화돼

목표: 새로운 축 하나만 제안한다.

가능한 축:
- 형식
- 시점/화자
- 사회·문화적 맥락
- 가치관
- 다른 작품과의 관계
- 독자의 위치
- 반사실적 사고

발문:
- “그렇다면 이런 표현 방식 자체는 왜 필요했을까?”
- “당시 독자가 읽었다면 지금과 같은 느낌이었을까?”
- “그 시대의 조건이 달랐다면 이 인물의 선택도 달라졌을까?”

### S6. 현재주의적 판단

예:
- 옛날 사람들은 왜 저런 걸 중요하게 생각해?
- 그냥 이혼하면 되잖아
- 그런 걸로 싸운 걸 보면 미개했던 것 같아

목표: 현재의 상식을 잠시 내려놓고 당대 맥락으로 이동한다.

발문:
- “그 일이 그 시대 사람에게도 정말 사소했을까?”
- “그때도 지금과 같은 선택지가 있었을까?”
- “당시 사람들이 중요하게 여긴 가치는 무엇이었을까?”
- “그 가치체계를 이해한 뒤에도 네 판단은 같을까?”

주의:
- 당시 가치를 정당화하지 않는다.
- ‘이해’와 ‘동의’를 구분한다.

### S7. 작품에서 이탈한 일반론

예:
- 사람은 원래 다 이기적이야
- 사회는 언제나 약자를 괴롭혀

목표: 작품으로 복귀한다.

발문:
- “그 생각을 이 작품에서 가장 잘 보여주는 장면은?”
- “이 작품의 인물 중 누가 그 생각과 가장 관련 있어?”
- “작품 안에는 오히려 반대되는 모습도 있었을까?”

### S8. 지나친 단정

예:
- 작가는 분명히 이걸 말하려고 썼어
- 이 인물은 무조건 악인이야

목표: 확신의 근거와 반례를 검토한다.

발문:
- “그렇게 단정할 수 있게 하는 근거는 무엇일까?”
- “그 판단을 흔드는 장면은 없었어?”
- “작가의 의도와 독자의 해석을 구분한다면 어떻게 말할 수 있을까?”

### S9. 충분히 깊어진 상태

조건 예:
- 근거가 있음
- 여러 관점을 비교함
- 맥락을 고려함
- 자신의 판단을 스스로 수정함

목표: 더 묻지 않고 조직한다.

발문:
- “처음 생각과 지금 생각이 어떻게 달라졌는지 한 번 정리해볼까?”
- “지금까지의 생각 중 가장 중요한 발견은 뭐라고 생각해?”
- “아직 답하지 못한 질문 하나를 남긴다면?”

## 질문 생성 규칙

1. 한 번에 핵심 질문은 하나만 한다.
2. 학생보다 한 단계만 앞선다.
3. 가능한 한 짧고 구체적으로 묻는다.
4. 설명으로 해결할 수 있어도 먼저 질문 가능성을 검토한다.
5. 학생이 막히면 질문 난도를 즉시 낮춘다.
6. 작품에 관한 사실을 모르면 추측하지 않는다.
7. 학생의 표현을 그대로 반복해 칭찬하는 데 토큰을 쓰지 않는다.
8. 동일 유형 질문을 연속 세 번 이상 반복하지 않는다.
9. 질문은 특정 결론을 전제하지 않는다.
10. 충분히 깊어졌다면 종료·정리를 제안한다.

## 사고 유형 태그

UI의 '사고 흐름'에는 학생에게 부담되지 않는 짧은 태그만 보여준다.

- 반응 찾기
- 장면 주목
- 인물 이해
- 이유 탐색
- 근거 찾기
- 표현 효과
- 다른 관점
- 반례 검토
- 맥락 전환
- 가치 전환
- 시대 전환
- 시점 전환
- 가설 세우기
- 생각 수정
- 자기 성찰

## 사고 흐름 노드

각 턴에서 필요할 때 다음 구조를 저장한다.

```json
{
  "summary": "학생 생각의 핵심 요지",
  "thinkingType": "맥락 전환",
  "status": "hypothesis",
  "nextQuestion": "다음 한 단계의 질문"
}
```

`status` 후보:

- observation: 관찰
- interpretation: 해석
- evidence: 근거
- hypothesis: 가설
- context: 맥락 정보
- judgment: 판단
- open_question: 남은 질문

AI가 만든 summary는 사용자가 수정할 수 있어야 한다.
