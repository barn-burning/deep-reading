# deep-reading data

이 디렉터리는 작품 전문이나 교과서 본문을 저장하지 않고, **공개된 교과서 메타데이터와 수록 관계**를 구조화하기 위한 초기 데이터셋입니다.

## 원칙

1. 교과서 메타데이터와 작품 지식은 분리한다.
2. 작품 전문·교과서 해설·문항 전문은 저장하지 않는다.
3. 각 레코드는 출처와 검수 상태를 가진다.
4. 출판사 공식 페이지에서 확인된 정보와 제3자 자료에서 확인된 정보를 구분한다.
5. 불확실한 항목은 추측해 채우지 않고 `candidate` 또는 `partial` 상태로 둔다.

## 파일

- `textbooks.json`: 교과서 단위 메타데이터와 대단원/소단원 구조
- `works.json`: 작품 자체의 최소 서지 메타데이터
- `textbook_works.csv`: 교과서 ↔ 작품 수록 관계
- `schema.md`: 장기 데이터 모델 초안
- `curriculum_standards.json`: 2022 개정 중학교 문학 성취기준
- `unit_standards.csv`: 교과서 소단원 ↔ 성취기준 대응(공식 명시/추론 구분)

## 검수 상태

- `verified_official`: 출판사/공식 교과서 페이지에서 확인
- `verified_secondary`: 서로 독립적인 공개 2차 자료에서 교차 확인
- `candidate`: 한 개의 2차 자료에서만 확인되어 추가 검수 필요
- `partial`: 정보 일부만 확인

## 현재 범위

2022 개정 교육과정의 **비상교육 중학교 국어 1-1 / 1-2 (대표저자 박현숙)** 를 첫 샘플로 사용합니다.

이 데이터셋의 목적은 전국 교과서를 한 번에 완성하는 것이 아니라, 실제 데이터 10~20건으로 스키마와 수집 파이프라인을 먼저 검증하는 것입니다.
